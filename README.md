# TopoCell — ელექტროლიზის ვირტუალური ლაბორატორია

**იდეის ავტორი:** ალექსანდრე გაგანაშვილი

ინტერაქტიული აპლიკაცია, რომელიც უჩვეულო გეომეტრიის ელექტროდებს (მიობიუსის ლენტი, კლაინის ბოთლით შთაგონებული გარსი) ჩვეულებრივ ელექტროდებთან ადარებს წყლის ელექტროლიზში.

**საკვლევი კითხვა:** შეუძლია თუ არა ასეთ ფორმებს გააუმჯობესოს წყალბადის წარმოება, ენერგიის ხარჯი ან მოწყობილობის კომპაქტურობა — და კონკრეტულად რა პირობებში?

აპლიკაცია წინასწარ არ თვლის, რომ იდეა მუშაობს: ერთნაირად აჩვენებს გაუმჯობესებასაც და მის არარსებობასაც, და ყველგან მიუთითებს, რა არის ფიზიკური კანონი, რა — საინჟინრო მოდელი, რა — მომხმარებლის დაშვება და რა — მხოლოდ ილუსტრაცია.

## რა შეუძლია

- **ოთხი პარამეტრული 3D სისტემა:** A — ბრტყელი ფირფიტები (საბაზისო); B — გადაუგრეხავი რგოლოვანი ლენტები (კონტროლი); C — ორი მიობიუსის ლენტი; D — კლაინის ბოთლი ორ რეჟიმში: მათემატიკური იმერსია (თვითგადაკვეთა მონიშნულია, გამოთვლაში არ მონაწილეობს) და ფიზიკურად დასაშვები მიახლოება (ფანჯრიანი გარსი + ცალკე რკალური ანოდი).
- **განლაგებები:** ერთმანეთის თავზე, გვერდიგვერდ, ჩადგმული (თუ გეომეტრიულად დასაშვებია), კონფორმული/სენდვიჩი; ანოდის გადაადგილება და მობრუნება; მინიმალური დაშორების კონტროლი; შეხებისა და თვითგადაკვეთის აკრძალვა.
- **ფიზიკური მოდელი:** ფარადეის კანონი, იდეალური აირი (სამუშაო და ნორმალური პირობები ცალ-ცალკე), E_rev(T, p), Butler–Volmer, U = E_rev + η_a + |η_c| + I·R; რეჟიმები — ფიქსირებული I, U ან P.
- **3D ამომხსნელი:** ∇·(κ∇φ) = 0 ვოქსელურ ბადეზე; პირველადი განაწილება (უჯრედის მუდმივა K) და მეორადი განაწილება (Butler–Volmer-ის სასაზღვრო პირობა); დენის ბალანსი, ბადის კრებადობა, 95-ე პერცენტილი, გაზის ჩაკეტვის გეომეტრიული ინდიკატორი.
- **სამართლიანი შედარება:** ელექტრული რეჟიმი და გეომეტრიული შეზღუდვა (მასალა / ფართობი / გაბარიტი) ცალ-ცალკე ირჩევა; ცხრილი მთლიანი უჯრედის დონეზე, % ცვლილებით საბაზისოსთან.
- **გრაფიკები:** I–U, H₂ სიმძლავრის მიხედვით, ენერგია წარმოების მიხედვით, გაზი დროში, ძაბვის შემადგენლები, მგრძნობელობა θ-სა და პარამეტრების მიმართ, გეომეტრიის პარამეტრის გავლენა.
- **ექსპერიმენტები:** სამი მომზადებული სცენარი; პარამეტრული სკანირება და ოპტიმიზაცია შეზღუდვებით და რიცხვითი გაურკვევლობით; შენახვა, აღდგენა, განმეორებადობის შემოწმება; CSV/JSON ექსპორტი და იმპორტი.
- **ინტერფეისი:** ქართული; მუქი და ნათელი თემა; კამერის ბრუნვა, მასშტაბი, გამჭვირვალობა, ჭრილი, ორი მოდელი გვერდიგვერდ; გამოთვლილი ველები და საილუსტრაციო ბუშტუკები ვიზუალურად გამიჯნულია.

## მეთოდოლოგია (მოკლედ)

სრული ვერსია ფორმულებით — აპლიკაციის ჩანართში **„მეთოდოლოგია“**.

**წარმოება (ფიზიკური კანონი).** ṅ(H₂) = η_F·I/(2F), ṅ(O₂) = η_F·I/(4F), V̇ = ṅRT/p. ფიქსირებული დენისა და ფარადეული ეფექტიანობისას H₂-ის მოლური ნაკადი ფართობზე, ფორმასა და ტოპოლოგიაზე დამოკიდებული არ არის.

**ძაბვა (საინჟინრო მოდელი).** U = E_rev(T, p) + η_a + |η_c| + I·(K/κ_eff + R_დამ). გადაძაბვები Butler–Volmer-ის განტოლებიდან, j = I/A_eff, A_eff = A_დასველებული·f_r·(1 − θ); κ_eff = κ(1 − ε)^1.5. θ მხოლოდ კინეტიკაში შედის, ε — მხოლოდ გამტარობაში (ეფექტი ორჯერ არ ითვლება); ორივე ყველა გეომეტრიისთვის ერთნაირია — არცერთ ფორმას „ეფექტიანობის ბონუსი“ არ ენიჭება.

**გეომეტრია.** მიობიუსის სხეული აიგება მართკუთხა კვეთის გადატანით, რომელიც მერიდიანულ სიბრტყეში ბრუნავს; ნაკერზე ბადე ინდექსების წანაცვლებით იკვრება (გლობალური ნორმალი არ გამოიყენება). შედეგი ჩაკეტილი ორიენტირებადი ზედაპირია (გვარი 1), მოცულობა ზუსტად 2πRwt (პაპუსი), დასველებული ფართობი ≈ იმავე ზომის რგოლისა. კლაინის ფიზიკური მიახლოება = იმერსია მინუს დისკო (ფანჯარა ყელის გარშემო): χ = −1, ერთი საზღვარი; გასქელება „ორმაგი დაფარვით“ → გვარი-2 სხეული. ყველაფერი ეს ტესტებით მოწმდება.

**3D ამომხსნელი.** სასრული მოცულობები კუბურ ბადეზე, იაკობის წინაპირობიანი შეუღლებული გრადიენტები. ელექტროდი ჩაშენებული საზღვარია: მანძილი ზედაპირამდე ნიშნიანი მანძილის ფუნქციიდან აიღება (Shortley–Weller-ის ტიპის სქემა), ამიტომ ვოქსელზე თხელი ელექტროდიც სწორ მანძილზეა. პირველადი განაწილება იძლევა მხოლოდ K-ს (R = K/κ) და კინეტიკას არ აღწერს; მეორადი — ნიუტონის იტერაცია BV სასაზღვრო პირობაზე. R = d/(κA) გამოიყენება მხოლოდ საორიენტაციოდ და ყოველთვის მონიშნულია.

**ბუშტუკები.** მრავალფაზიანი ნაკადი არ მოდელირდება. ანიმაცია საილუსტრაციოა; θ და ε მომხმარებლის დაშვებებია. გაზის ორი ინდიკატორი („პირდაპირი განიავება“ და „ჰიდროსტატიკური ჯიბე“) წმინდა გეომეტრიულია და ჰიპოთეზის დონეზე რჩება. საერთო ელექტროლიტში H₂ და O₂ ერევა — რეალურ უჯრედს დიაფრაგმა და ცალკე გაზშემკრებები სჭირდება.

## კვლევითი შეჯამება (აუდიტის შემდეგ)

სრული აუდიტი, ცხრილები და თითო რიცხვის წყარო — [AUDIT.md](AUDIT.md). ქვემოთ მოყვანილი რიცხვები ექსპერიმენტების ფაილებიდან ავტომატურად ივსება. ისინი ეკუთვნის ნაგულისხმევ, **საილუსტრაციო** პარამეტრებს და მოდელის შედეგია, არა მოწყობილობის პროგნოზი.

### რა აჩვენა მოდელმა გამოკვლეულ კონსტრუქციებზე

1. **ერთნაირ დენზე H₂ ერთნაირია** (93.28 mmol/h 5 A-ზე ოთხივე სისტემაში) — ფარადეის კანონისა და η_F = 1 დაშვების შედეგი. გეომეტრია მოქმედებს მხოლოდ ძაბვაზე.
2. **ცალმხრივობა ფართობს ან მასალას არ ამატებს:** იმავე ზომის რგოლი და მიობიუსის ლენტი — 3.14 და 3.14 სმ³, 66.0 და 66.4 სმ².
3. **გადაგრეხის ეფექტი განლაგებაზეა დამოკიდებული.** ერთმანეთის თავზე, ერთნაირი მინიმალური დაშორებით, გადაგრეხილი ლენტების K (4.70 1/m) 1.9-ჯერ მეტია ბრტყელი რგოლებისაზე (2.45), მაგრამ ტოლია გადაუგრეხავი ცილინდრული რგოლისა (4.70); გვერდიგვერდ გადაგრეხა ბრტყელ რგოლს სჯობს (8.65 და 11.82). K მჭიდროდ მიჰყვება ზედაპირების საშუალო დაშორებას (სპირმენის ρ = 0.94); ორიენტირებადი n = 2 და არაორიენტირებადი n = 1 ერთნაირ განლაგებაში 0.5 %-ით განსხვავდება.
4. **ორმხრივი განლაგება ეკონომიას იძლევა, ფორმის მიუხედავად.** ერთნაირი მასალითა და 5 A-ზე (სივრცული მოდელი, N = 64, kWh/kg): კონფორმული რგოლი 59.54, კონფორმული მიობიუსი 59.61, ფირფიტების სენდვიჩი 60.15, ფირფიტების წყვილი 61.27. ფირფიტების წყვილთან შედარებით კონფორმული მიობიუსის ეკონომია 2.5 ± 0.3 %-ია (პირობების მიხედვით 0.6–4.7 %), 3.4-ჯერ დიდი გაბარიტის ფასად.
5. **კონფორმული რგოლი და კონფორმული მიობიუსი არ გაირჩევა:** ერთნაირი N-ის ბადეებზე ΔU ≈ +0.5 mV, სხვა დისკრეტიზაციით −2.9…+3.6 mV; ღრეჩოს განსაზღვრის კონვენცია სხვაობას −5.4 mV-ით ცვლის (ნიშანი იცვლება), ხოლო არამოდელირებული ლითონის წინაღობა იმავე რიგისაა (≈ 0.5 mV).
6. **კლაინის ტიპის გარსში დენი ძლიერ არათანაბრად ნაწილდება** (კინეტიკურად ეკვივალენტური ფართობი დასველებულის ≈ 50–54 % ყველაზე წვრილ ბადეზე; რიცხვი ბადესთან ერთად კლებულობს). ერთნაირი მასალით მისი ხარჯი 63.4 kWh/kg-ია. შედეგი ერთ კონკრეტულ (გარე, რკალურ) ანოდს ეკუთვნის.
7. **გეომეტრიული ჰიპოთეზა:** კლაინის გარსში ფანჯრის ზედა კიდის ზემოთ არის ≈ 27 სმ³ ჰიდროსტატიკური ჯიბე (კათოდის ფართობის ≈ 18–21 %), რომელიც ფანჯრის ღრეჩოდან იღვრება. ივსება თუ არა ის რეალურად გაზით — მოდელი ვერ ადგენს.

**მთავარი დასკვნა.** გამოკვლეული კონსტრუქციებისა და პარამეტრების ფარგლებში მოდელმა ვერ გამოავლინა ტოპოლოგიის (ცალმხრივობის, არაორიენტირებადობის) დამოუკიდებელი უპირატესობა: ყველა გარჩევად სხვაობას თან ახლდა განლაგების, დაშორების ან ფართობის სხვაობა, და იქ, სადაც ეს ფაქტორები მაქსიმალურად გათანაბრდა, სხვაობა გარჩევადობის ზღვარზე დაბალი აღმოჩნდა. ეს **არ არის** მტკიცება, რომ ასეთი უპირატესობა არცერთ კონსტრუქციაში არ არსებობს: მოდელი ვერ ამოწმებს იმ არხებს, რომლებიც მასში არ შედის.

### რა ვერ დაადგინა მოდელმა

- მოდელში არ არის ბუშტუკების დინამიკა, კონვექცია, კონცენტრაციული პოლარიზაცია, ტემპერატურული ველი, დიაფრაგმა და ლითონის წინაღობა; θ და ε ყველა ფორმისთვის ერთნაირი დაშვებაა. ამ არხებით გამოწვეულ უპირატესობას ან ზიანს მოდელი სტრუქტურულად ვერ დაინახავს და ვერც მათ შედარებით წონას შეაფასებს.

3. **ძაბვა–დენის მახასიათებლები** ერთნაირი მასალით, დაშორებითა და ელექტროლიტით, განმეორებებითა და ცდომილების შეფასებით; კონფორმული რგოლისა და მიობიუსის გასარჩევად საჭიროა ≈ 1 mV-ზე უკეთესი განმეორებადობა.
4. **გაზის ფაქტობრივი გამოსავალი** — ფარადეული ეფექტიანობისა და გაზების ურთიერთშეღწევის გასაზომად.
5. **ბუშტუკების დაფარვა და მოცილება:** ჩქაროსნული ვიდეოგადაღება სხვადასხვა ორიენტაციასა და დენის სიმკვრივეზე; ძაბვის დრეიფი დროში; კლაინის გარსში — ივსება თუ არა ჯიბე და საიდან გადის გაზი.
6. **დენის განაწილება:** სეგმენტირებული ელექტროდი ან ლოკალური პოტენციალის ზონდი.
